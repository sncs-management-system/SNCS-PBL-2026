# SNCS brand and asset audit

Audit date: 2026-09-30
Source: [sncstaguig.com](https://www.sncstaguig.com/)

## Redesign boundary

This MVP modernizes the information architecture, responsiveness, accessibility, and visual hierarchy. It does not replace the school identity. The official seal, established red-led palette, institutional typography cues, motto, and existing public photography remain recognizable across the redesign.

## Visual identity carried forward

- Primary institutional red: `#CC1300`, sampled from the current website's major section background.
- Supporting deep reds: `#7E160D` and `#3C0B08`, used as accessible tonal extensions of the primary color.
- Warm gold: `#E3AD2F`, drawn from the seal and retained as a restrained accent.
- Neutrals: white, warm cream, charcoal, and black.
- Display serif: Playfair Display on the current school name; the redesign uses the same family with a Georgia fallback.
- Condensed display: Oswald on current section labels; the redesign uses the same family with an Arial Narrow fallback.
- Body sans serif: Open Sans on the current website; the redesign uses the same family with system fallbacks.
